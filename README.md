🚀 Deployed My Web Application on K3s Running on AWS EC2!

I recently completed a hands-on deployment where I containerized a simple web application using Docker and deployed it on a K3s Kubernetes cluster running on an AWS EC2 instance.

🛠️ What I worked with:

🔹 AWS EC2 – Hosting the K3s cluster
🔹 Docker – Containerizing the application
🔹 Docker Hub – Storing and pulling the Docker image
🔹 K3s / Kubernetes – Deploying and managing the application
🔹 Kubernetes Deployment & Service – Managing application workloads and networking
🔹 NGINX Ingress Controller – Exposing the application externally
🔹 GoDaddy DNS – Connecting my domain to the EC2 instance
🔹 Git & GitHub – Managing the project

🔄 Deployment Flow:

Application → Docker Image → Docker Hub → K3s on EC2 → Deployment → Service → NGINX Ingress → Domain 🌐

I also faced and resolved a port configuration issue during the deployment, which helped me better understand how containerPort, targetPort, Service ports, and Ingress ports work together in Kubernetes.

This project gave me more practical experience with containerization, Kubernetes networking, AWS infrastructure, and application deployment.
